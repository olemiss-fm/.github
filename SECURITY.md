# Security policy

This policy covers every repository in the olemiss-fm organization
(University of Mississippi Facilities Management).

## Reporting a vulnerability

Email fmsupport@olemiss.edu with a description of the issue and the steps to
reproduce it. Do not open a public issue, pull request, or discussion for a
suspected vulnerability.

Expect an acknowledgment within 3 business days. A confirmed issue gets a fix
or a mitigation plan, and the reporter is told which one. A declined report
gets a short explanation.

## Supported versions

These repositories hold internally deployed applications and operations
tooling, not versioned libraries. Only the code currently deployed from the
`main` branch is supported. Older tags and releases receive no security fixes.
